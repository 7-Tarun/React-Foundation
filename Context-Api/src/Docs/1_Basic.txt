Problem: Prop Drilling
-The default rule of React data can only flow from parent to child via props.

Example:
        App → Dashboard → Sidebar → Top → Card
-App has the user data, Card needs it.

This unnecessary prop passing is called Prop Drilling.


Solution: The solution is to create a global object (Context API / Redux).
-Create a shared data source (Context). 

Components like Card can access the data directly from Context instead of passing props through intermediate components.
